# IronWomen-Bot
Hypixel SkyBlock has a gamemode called Ironman where you are unable to trade with anybody. A while ago, me and my friend started an Ironman profile together and called it "IronWomen".

This is the Discord bot we used to track our progress. It's relatively bare bones but it was nice to have, especially the bank monitor.
